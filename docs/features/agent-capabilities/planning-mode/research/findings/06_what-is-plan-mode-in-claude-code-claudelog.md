## Summary
Plan Mode is a safety feature in Claude Code. Plan Mode allows Claude to research and analyze without making changes. Claude cannot edit, create, or execute anything in Plan Mode. Plan Mode requires user approval before any actions are taken. Claude can read files in Plan Mode.
