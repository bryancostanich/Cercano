## Summary
Conductor is a plugin for AI coding agents (Antigravity, Claude Code) that enables Spec-Driven Development with a defined lifecycle: Context → Spec & Plan → Implement.. The plugin was last updated on 2024-04-05 (2 weeks ago from the current date of 2024-04-19).. Conductor structures development tasks into three distinct stages: (1) Context, (2) Specification and Planning, and (3) Implementation, ensuring reproducibility and quality control.. The plugin integrates with Antigravity and Claude Code, which are AI-powered coding assistant tools, to enforce structured workflows.. Conductor enables developers to generate project-specific design specifications before writing code, reducing errors and increasing alignment with requirements..
